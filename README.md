# Complex Number Calculator

A C++ project that implements arithmetic operations on complex numbers using operator overloading.

## Features

The `Complex` class supports the following operations:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Operations between two complex numbers.
- Operations between a complex number and a real number.
- Division-by-zero exception handling.
- Displaying complex numbers in a readable format.

## Complex Number Representation

A complex number has two components:

\[
z = a + bj
\]

Where:
- `a` represents the real part.
- `b` represents the imaginary part.
- `j` represents the imaginary unit.

## Example

Given:

```text
c1 = 1 + 2j
c2 = 7 + 5j
```

Multiplication:

```text
c2 * c1 = -3 + 19j
```

Division:

```text
c2 / c1 = 3.4 - 1.8j
```
